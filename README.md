# 방 배정 프로그램 — 복사해서 내 걸로 쓰기

연수생이 폰으로 숙박 여부와 같은 방 희망을 고르면, 프로그램이 규칙에 맞춰 방을 배정해 줍니다.
이 저장소를 **내 GitHub로 복사**하면 **내 화면 주소 + 내 구글 서버 + 내 데이터**로 따로 쓸 수 있어요. 다른 사람과 섞이지 않습니다.

- 연수생: 구글 계정 없이 주소만 열면 됩니다. (아이폰 가능)
- 명단·선택·배정 내용: **내 구글 드라이브의 "방배정 데이터" 시트**에만 저장됩니다.
- 한글(hwpx) 숙소배치도, 카드키 수불부(엑셀) 내려받기 포함.
- 약 15분 걸리고, 프로그램을 설치할 필요는 없습니다.

> 그림으로 한눈에 보는 안내는 `guide.html` (내 화면 주소 뒤에 `/guide.html`)에 있어요.

## 준비물
- GitHub 계정 (없으면 github.com에서 무료로 가입)
- 구글 계정 — **개인 계정(@gmail.com)을 권장**합니다. 학교·기관 계정은 관리자가 "모든 사용자에게 공개 배포"를 막아 두는 경우가 있어요.

## 설치 순서

### 1. 내 저장소 만들기
이 페이지 오른쪽 위의 초록색 **Use this template → Create a new repository** 를 누릅니다.
- Repository name: `roomassign` (아무 이름이나 괜찮아요)
- **Public** 선택 (무료 계정은 공개 저장소여야 화면 주소를 만들 수 있어요)
- **Create repository**

> 나중에 원본의 새 기능을 받아 쓰고 싶다면 "Use this template" 대신 오른쪽 위 **Fork**로 복사하세요. 새 기능이 나오면 **Sync fork** 버튼으로 가져올 수 있어요.

### 2. 내 화면 주소 켜기
내 저장소에서 **Settings → Pages**
- Source: **Deploy from a branch**
- Branch: **main**, 폴더 **/ (root)** → **Save**

1~2분 뒤 내 화면 주소가 생깁니다. `https://내아이디.github.io/저장소이름/`

### 3. 내 구글 서버 만들기
1. <https://script.google.com> → **새 프로젝트**, 이름은 "방배정" 등 아무거나.
2. 왼쪽 ⚙ **프로젝트 설정** → "**'appsscript.json' 매니페스트 파일 표시**" 체크 → 왼쪽 `< >` 편집기로 돌아옵니다.
3. 이 저장소의 `apps-script` 폴더에 있는 파일 5개를 하나씩 열어 내용을 복사(파일 화면 오른쪽 위의 복사 버튼)해서 붙여넣습니다.
   - `appsscript.json` → 편집기의 appsscript.json 내용을 전부 지우고 붙여넣기
   - 기본 `코드.gs`는 삭제
   - ＋ → **스크립트**: 이름 `Assign` ← `Assign.js`, `Store` ← `Store.js`, `Api` ← `Api.js`
   - ＋ → **HTML**: 이름 `Index` ← `Index.html`
   - 저장(Ctrl+S)
4. 오른쪽 위 **배포 → 새 배포** → 톱니바퀴 → **웹 앱**
   - 실행 사용자: **나**
   - 액세스 권한: **모든 사용자**
   - **배포** → 권한을 물으면 허용 ("확인되지 않은 앱"이 나오면 **고급 → 이동 → 허용**)
5. 나온 **웹 앱 URL**을 복사해 둡니다. `https://script.google.com/macros/s/`**`긴글자`**`/exec`

### 4. 화면에 내 서버 알려 주기
내 저장소에서 `config.js` 파일을 열고 오른쪽 위 연필(✎)을 눌러 고칩니다.

```js
apiId: '여기에 3번에서 복사한 웹 앱 URL 또는 긴 글자',
```

→ **Commit changes**. 1~2분 뒤 반영됩니다.

### 5. 시작하기
`https://내아이디.github.io/저장소이름/#admin` 을 엽니다. (즐겨찾기에 추가하세요)
처음에 **관리자 비밀번호**를 정하면 "방배정 데이터" 시트가 내 드라이브에 만들어집니다.
**새 연수 만들기**를 하면 **연수생 주소**가 자동으로 나옵니다. 그 주소를 연수생에게 보내세요.

## 연수 진행 순서
**① 명단 올리기 → ② 객실·옵션 → (연수생 응답 받기) → ④ 자동 배정 → 조정 → 확정·공개**
연수생은 휴대전화 번호로 본인 확인을 하고, 내 이름표를 출근/숙박/같은 방 요청 칸으로 끌어다 놓아 고릅니다.

## 문제가 생기면
- **"서버(배포 ID)가 아직 설정되지 않았어요"**: 4단계의 `config.js`에 배포 ID를 넣었는지 확인하세요.
- **"서버에 연결할 수 없어요"**: 3번의 액세스 권한이 **모든 사용자**인지, `config.js`의 ID가 한 글자라도 틀리지 않았는지 확인하세요.
- **관리자 화면이 안 열려요**: 화면 주소 끝에 `#admin`을 붙였는지, 2단계 Pages가 켜졌는지 확인하세요.
- **서버 코드를 고쳤다면**: 배포 → 배포 관리 → ✎ 편집 → 버전: **새 버전** → 배포. (주소는 바뀌지 않아요)

## 알아 둘 점
- 연수생 전화번호는 해시로만 저장되고 화면에는 끝 4자리만 보입니다. 실제 명단은 내 구글 시트에만 있고 이 저장소에는 없습니다.
- 내 저장소를 **비공개로 바꾸면** 무료 계정에서는 화면 주소가 꺼집니다.
- 화면 맨 아래의 `Prompted by kidsreturn_79` 표시는 원 제작자 표기입니다.
