주는 법

상대 상황에 맞게 한 가지를 고르세요.

A. 링크로 주기 권장

상대: GitHub 계정(무료) + 구글 계정
  • 링크 한 줄과 이 문서만 보내면 끝
  • 상대가 Use this template 버튼으로 자기 저장소를 만듭니다
  • 새 기능이 나오면 Fork로 받으면 편해요
보낼 것
https://github.com/ttorwai-stack/roomassign-template

B. 파일(zip)로 주기

상대: GitHub 계정 + 구글 계정 (링크를 못 쓸 때)
  • 소스 zip 하나와 이 문서를 카톡·메일로 전달
  • 상대는 zip을 풀어 자기 저장소에 Add file → Upload files로 폴더째 끌어다 놓습니다
보낼 것
방배정_복사용_소스.zip

C. GitHub 없이 주기

상대: 구글 계정만
  • 구글 서버만 만들고, 화면은 원 제작자의 공용 주소를 함께 씁니다 (데이터는 내 구글 시트)
  • 원 제작자 화면이 내려가면 영향을 받는 게 단점
보낼 것
ttorwai-stack.github.io/roomassign/guide.html
줄 때 이 네 가지는 꼭 말해 주세요
  • 개인 구글 계정(@gmail.com)으로 하세요. 학교·기관 계정은 "모든 사용자 공개" 배포가 막혀 있을 수 있어요.
  • GitHub 저장소는 Public(공개)으로 만드세요. 무료 계정은 비공개면 화면 주소가 꺼집니다.
  • 관리자 비밀번호는 본인이 정하고 직접 보관하세요.
  • 명단은 본인 구글 시트에만 있고, 저장소에는 올라가지 않아요. 연수 정보를 저장소에 올리지 마세요.

켜는 법 · 받은 사람이 하는 일 (약 15분)

프로그램 설치는 필요 없고, 웹 화면에서 클릭과 붙여넣기만 합니다.

  1. 1

    내 저장소 만들기

    링크를 열고 Use this template → Create a new repository. 이름 예: roomassign, Public 선택, Create.

    약 2분
  2. 2

    내 화면 주소 켜기

    내 저장소 Settings → Pages → Branch main / / (root) → Save. 1~2분 뒤 https://내아이디.github.io/저장소이름/ 이 생겨요.

    약 2분
  3. 3

    내 구글 서버 만들기

    script.google.com → 새 프로젝트 → 저장소의 apps-script 폴더 파일 5개를 복사해 붙여넣기 → 배포 → 새 배포 → 웹 앱 (실행: 나 / 액세스: 모든 사용자) → 권한 허용. 나온 웹 앱 URL을 복사합니다.

    약 8분
  4. 4

    화면에 내 서버 알려 주기

    내 저장소의 config.js를 열어 연필(✎)로 고치고 apiId 칸에 웹 앱 URL을 붙여넣은 뒤 Commit changes.

    약 1분
  5. 5

    관리자 시작

    내 화면 주소/#admin을 열고 관리자 비밀번호를 정합니다. 이때 내 드라이브에 "방배정 데이터" 시트가 자동으로 만들어져요.

    약 1분
✅ 관리자 주소 (즐겨찾기)https://내아이디.github.io/저장소이름/#admin
✅ 연수생 주소 (연수마다 자동 생성)…/저장소이름/?c=연수코드 — 관리자 화면에서 복사
③

관리하는 법

켠 뒤에는 관리자 화면에서 연수만 계속 만들면 됩니다.

연수 한 번의 흐름

연수 만들기›① 명단 올리기›② 객실·옵션›연수생 응답 받기›④ 자동 배정·조정›확정·공개›한글 배치도·카드키 수불부 내려받기›종료 후 보관

연수마다 명단·방 설정·배정이 따로 저장돼요. 다음 연수는 지난 연수의 방 설정을 복사해서 시작할 수 있어요.

📒 데이터는 어디에?

  • 내 구글 드라이브의 "방배정 데이터" 시트 한 곳에만 있어요. (연수마다 시트 탭이 따로)
  • 백업: 시트를 열어 파일 → 사본 만들기
  • 보관 버튼: 연수생 접속은 막고 데이터는 남겨 둡니다
  • 전화번호는 해시로만 저장, 화면엔 끝 4자리만 보여요
  • 보관 기간이 지난 명단은 기관 규정에 맞게 시트에서 지우세요

🔄 새 버전이 나오면

바뀐 것받은 사람이 할 일
화면 (index.html, 틀 파일)Fork면 Sync fork 버튼. 템플릿이면 새 파일로 교체 (config.js는 그대로)
서버 (apps-script 폴더)구글에 다시 붙여넣기 → 배포 → 배포 관리 → ✎ → 새 버전 → 배포
안내문만할 일 없음

무엇이 바뀌었는지는 새 버전을 줄 때 함께 알려 주세요.

🛠️ 문제가 생기면

증상확인할 것
"서버(배포 ID)가 아직 설정되지 않았어요"config.js에 배포 ID를 넣고 Commit 했는지
"서버에 연결할 수 없어요"웹 앱 액세스가 모든 사용자인지, 배포 ID가 한 글자라도 틀리지 않았는지
관리자 화면이 안 열려요주소 끝에 #admin, Pages가 켜졌는지(켠 뒤 1~2분)
"확인되지 않은 앱" 경고정상이에요. 고급 → 이동 → 허용
연수생이 번호를 잘못 입력해 못 들어와요관리자 명단에서 그 사람의 본인 확인을 해제
서버 코드를 고쳤는데 반영이 안 돼요배포 관리에서 새 버전으로 다시 배포했는지
